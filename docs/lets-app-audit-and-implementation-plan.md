# レッツ向けアプリ評価と実装計画（2026-02-08）

## 1. 目的
`lets-context.md` と `product-direction-options.md` を前提に、現行アプリを「レッツらしさ」に寄せるための評価、受容性チェック、実装計画を明文化する。

## 2. 評価軸（レッツ基準）
1. 主体性（自走力）を上げる設計か
2. ワクワクと安心を両立できるか
3. 運営工数の削減に寄与するか
4. 外部体験導線が不自然なく受け入れられるか
5. 不安煽り・数字偏重に寄らないか

## 3. 現状評価（主要画面）
### Login
- 良い点:
  - 会員番号/メール/ゲスト開始に対応しており、入口が広い
- 改善点:
  - 外部ユーザー向け体験価値の説明が弱く、無料体験導線が埋もれやすい

### Home（Dashboard）
- 良い点:
  - 最近の挑戦、学習サマリー、コース選択があり再開導線は明確
- 改善点:
  - 生徒が「自分で今日の目標を選ぶ」仕組みがない
  - 継続動機（連続学習など）の見える化が弱い

### Course / Play / Choice
- 良い点:
  - 学習導線と結果表示は一貫している
- 改善点:
  - 結果は見えるが「自分で選んだ目標との接続」がない

### Admin
- 良い点:
  - 多面的なフィルタ・詳細編集・運用サマリがある
- 改善点:
  - 日常運用で頻出の手順（要フォロー抽出、未着手抽出、報告用CSV作成）がワンクリック化されていない

## 4. 外部アプリ比較（受容性チェック）
受容性判断は、一般ユーザーが慣れている教育アプリの基本パターンに照らして行う。

### 参考にした公開情報
- Duolingo: 連続学習・学習習慣化（Streak）  
  [Duolingo Streak Society](https://blog.duolingo.com/streak-society/)
- Khan Academy: 学習の完了率/進捗を可視化  
  [Khan Academy Progress Reports](https://support.khanacademy.org/hc/en-us/articles/360008655632-How-can-I-use-Progress-Reports-in-Khan-Academy)
- ClassDojo: 学校-家庭のコミュニケーション導線  
  [ClassDojo Families](https://www.classdojo.com/families/)
- Google Material 3: 使われるUIの一貫性原則  
  [Material 3 Overview](https://m3.material.io/)

### 受容性の結論
1. 自主目標選択と連続学習可視化は、教育アプリ文脈で違和感がない
2. 管理画面のワンクリック抽出・CSV出力は、運営実務で一般的で受容性が高い
3. 無料体験CTAの明示は、初見ユーザーの行動を促す標準パターン

## 5. 実装優先（確定）

2. テーマ1: 生徒の自走・継続
3. 外部集客の最小導線
4. テーマ2: 保護者安心の拡張

## 6. 今回の実装範囲
1. Admin: 業務置換クイック操作（要フォロー/未着手/直近アクティブ抽出）
2. Admin: フィルタ結果のCSV出力
3. Home: 今日の自主ミッション（自分で目標選択）
4. Home: 連続学習日数とミッション達成状態の表示
5. Login: 無料体験訴求ブロックとCTA強化
