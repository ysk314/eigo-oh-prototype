# Alphabet Bridge カリキュラム v4（ゼロベース再設計）

最終更新: 2026-02-08

## 1. 再設計の狙い
前回の課題だった「出題意図の混在」を解消するため、
Alphabet Bridgeを次の3段階で再設計。

1. 基礎: 大文字を確実に取れる
2. 橋渡し: 小文字と大小ペアを往復できる
3. 運用: キーワードと結びつけて取り出せる

## 2. ルール
- 骨格は共通: `Unit > Part > Section`
- 学習文字セットは各Sectionで共通
- 問題はモード別・レベル別で分離
  - `typing-only + typing-l1/l2/l3`
  - `choice-only + choice-l1/l2/l3/l4`

## 3. レベルの意味
### タイピング
- L1: 大文字入力（基礎）
- L2: 小文字入力（橋渡し）
- L3: 大小セット入力（統合）

### 4択
- L1: 名前/手掛かり -> 大文字記号
- L2: 名前/手掛かり -> 小文字記号
- L3: 文字 -> キーワード（連結）
- L4: 意味 -> 英語キーワード（逆引き）

## 4. カリキュラム
## Unit 1: 基礎（大文字の定着）
- Part: A-L
  - A-D
  - E-H
  - I-L
- Part: M-Z
  - M-P
  - Q-T
  - U-Z

## Unit 2: 橋渡し（小文字・ペア・形の違い）
- Part: 小文字フォーカス
  - A-L 小文字
  - M-Z 小文字
- Part: ペア入力フォーカス
  - A-L ペア
  - M-Z ペア
- Part: まぎらわし文字
  - B/D/P/Q + I/L/J/T + U/V/W/Y

## Unit 3: 運用（取り出しと定着）
- Part: キーワード連結
  - A-I
  - J-R
  - S-Z
- Part: 総合マスター
  - 全26ミックス

## 5. 出題例
### タイピングL1
- `文字名「エー」の大文字を入力` -> `A`
- `「ねこ」の頭文字（大文字）を入力` -> `C`

### タイピングL3
- `文字名「ビー」のセット（大→小）を入力` -> `Bb`

### 4択L2
- 問題: `文字名「ディー」の小文字`
- 正答: `d`

### 4択L4
- 問題: `「しまうま」の英語`
- 正答: `zebra`
